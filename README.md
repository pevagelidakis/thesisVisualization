# Thesis Visualization
This repo stores the script for my thesis: A Comperative Analysis of robust variable selection on Time Series Data. You are encouraged to clone and run the code. The app.R is the file that visualize the entire work in a shiny application. In case you need to run it, you can use the command  `shinyApp(ui, server)` elswise you can run it using `runApp(app.R)`
